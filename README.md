# Online Sales Analysis

## Opis projekta

Ovaj projekat predstavlja jednostavan sistem za upravljanje proizvodima i korpom za kupovinu, razvijen u Python programskom jeziku.

## Klase

### Product
Klasa `Product` predstavlja proizvod i sadrži:
- naziv proizvoda
- cenu
- količinu

Omogućava prikaz informacija o proizvodu i ažuriranje količine.

### ProductManager
Klasa `ProductManager` služi za upravljanje listom proizvoda. Omogućava:
- dodavanje proizvoda
- prikaz proizvoda
- računanje ukupne vrednosti inventara
- uklanjanje proizvoda po nazivu

### Cart
Klasa `Cart` predstavlja korpu za kupovinu i omogućava:
- dodavanje proizvoda u korpu
- računanje ukupne vrednosti korpe
- prikaz sadržaja korpe

## Funkcionalnost

Program omogućava kreiranje i upravljanje proizvodima, uklanjanje proizvoda, kao i formiranje korpe sa nasumično odabranim proizvodima.

Projekat koristi Git za praćenje verzija, rad sa granama, commit-ovanje promena, spajanje grana i rešavanje konflikata.
